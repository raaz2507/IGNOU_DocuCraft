## ✨ Features & Capabilities

### 🎓 1. MCA MCSP-232 Project Synopsis Kit
A complete 4-document studio built according to official IGNOU guidelines:

* 📄 **Annexure II (Project Proposal Proforma):**
  * Separate rows for **RC Code** and **Regional Centre**.
  * Multi-select degree checkboxes for Project Guide (PhD, M.Tech, BE/B.Tech, MCA, M.Sc).
  * Quick Tech-Stack chips from Section VIII (Python, Django, React, PostgreSQL, etc.).
  * Student & Guide signature blocks with independent dates.
* 📜 **Project Trainee Request Letter:**
  * Official School letterhead (SOCIS emblem, New Delhi address).
  * Underlined student credentials & Regional Director stamp block.
* 📑 **Annexure X (Certificate of Originality):**
  * Full official authenticity declaration with dual signature layout and 2-line address blocks.
* 🎨 **Annexure XI (Project Report / Synopsis Cover Page):**
  * Curved university header text matching the official emblem font.
  * **Border Style Options:**
    * `Option A`: Official Double Border (University Classic).
    * `Option B`: Executive Single Border (Clean & Sharp).
    * `Option C`: Borderless (Ideal for spiral or hard-bound binding).
  * **Center Watermark:** Official IGNOU emblem seal (5.5% subtle opacity, prints behind text).
  * **Paper Tone:** Standard Pure White or Subtle Ivory.
  * **Automatic Title-Case:** Student and Guide names automatically formatted in clean Title Case (`Raj Kamal`, `Neha Khan`).

* 📚 **Pre-configured Courses:** Complete theoretical and practical lab courses for **MCA_NEW Semesters 1 to 4**.

* 🖌️ **Auto White-Background Removal:** Upload a phone photo of your physical signature on white paper; the built-in canvas processor automatically removes the background and generates a clean, transparent ink signature.

## 🖨️ Recommended Print Settings (Zero Margin Guide)

To ensure double borders and headers print cleanly without edge clipping, set these in your browser print dialog:

| ⚙️ Setting | 📌 Recommended Value | 💡 Why It Matters |
| :--- | :--- | :--- |
| **Destination** | **Save as PDF** or your Printer | Keeps layout vector-sharp |
| **Paper Size** | **A4 (210 × 297 mm)** | Official IGNOU standard |
| **Margins** | **None** *(Crucial!)* | Default margins cause borders to clip |
| **Background Graphics** | **ON (Checked ✓)** | Ensures university logo and watermarks print |
| **Headers & Footers** | **OFF (Unchecked ✕)** | Prevents browser URLs/dates on top and bottom |
